Why

The Claude desktop app holds one account at a time. Changing it means signing out, which throws the sign-in away, signing in with the other address and waiting for an email code. Then the Claude Code chat you were in is gone from the sidebar, because Claude lists chats per account. And you only see the usage of the account you are signed in to.

What it does

Keeps every sign-in

Each account's sign-in is saved and put back when you switch to it. You type an email code once per account.

Switches in one click

Pick an account in the tray menu. Claude restarts signed in to it in about ten seconds.

Brings your chats along

Claude Code chats and projects of your other accounts are copied into the one you switch to, and chats that were mid-reply pick up where they stopped. Deleted chats stay deleted.

Shows usage of every account

Live 5-hour and weekly usage for all saved accounts, with reset times. The tray icon fills as the active account gets used.

Can switch on its own

Off by default. Turn it on and it moves to the account with the most room left before you hit the limit.

Stays on your machine

Tokens stay encrypted as Claude stored them and go nowhere but api.anthropic.com.

Get started

  1. Download the file for Windows 10/11 or macOS and run it while you are signed in to Claude. On Windows you can also run winget install SnlperStripes.ClaudeAccountSwitcher and start it with claude-account-switcher.
  2. Choose Add account… in its tray menu and sign in with your second account.
  3. From then on, click an account to switch. Turn on Start at login so it is always there.

The builds are not code-signed, so Windows SmartScreen and macOS Gatekeeper warn once. The install notes show how to get past that.

FAQ

Can the Claude desktop app be signed in to two accounts at once?

Not on its own. The app holds one sign-in at a time, and switching means signing out and waiting for an email code. Claude Account Switcher keeps a saved sign-in for every account and swaps between them in about ten seconds.

How do I switch Claude accounts without signing out?

Install the switcher, add each account once with Add account…, then pick an account from the tray menu. You never use Sign out again.

What happens to my Claude Code chats when I switch accounts?

They come along. The switcher copies the chat list and projects of your other accounts into the one you switch to, so the chat you were in shows up in the sidebar and you can keep going.

How do I see the usage of all my Claude accounts at once?

The tray menu shows 5-hour and weekly usage of every saved account, live, with when each limit resets. claude-account-switcher -status prints the same in a terminal.

What can I do when I hit the Claude usage limit?

Switch to an account that has room left, or let Auto-switch do it for you shortly before the limit.

Does it work with the Microsoft Store version of Claude?

Yes. It finds the Store app's real data folder and works with the direct download too, on Windows 10 and 11.

Does it work on macOS?

It builds for macOS (universal), but nobody has tested it on a real Mac yet. A test report helps.

Does it switch the Claude Code CLI in the terminal?

No. It switches the Claude desktop app, including the Claude Code chats inside it. The claude command in a terminal keeps its own sign-in, and the switcher does not touch it.
